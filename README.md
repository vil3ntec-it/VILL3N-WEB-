# VILL3N — سایتِ vill3n.top

سایتِ دانلودِ برنامه‌های VILL3N با پنلِ مالک. فقط Node.js 18+ لازم است؛ هیچ بستهٔ npm ندارد.

## به‌روزرسانی

```
این ریپو  ──▶  کنترول سنتر (سرورِ خانگی، هر ۱۰ دقیقه)  ──▶  سایت (هر ساعت)
```

- سایت هیچ نشانیِ GitHub نمی‌شناسد؛ نشانیِ آینه را کنترول سنتر در `SITE_UPDATE_URL` به آن می‌دهد.
- هر فایل با sha256ِ `release.json` سنجیده می‌شود؛ پوشهٔ `data` و `config.json` هرگز دست نمی‌خورند.
- **هر تغییرِ کد**: نسخهٔ `package.json` را بالا ببرید و `node scripts/make-release.js` را بزنید.

راهنمای کامل: `docs/راهنما.md` و `اتصال-به-کنترول-سنتر.txt`.
